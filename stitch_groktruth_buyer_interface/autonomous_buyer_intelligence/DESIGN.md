## Brand & Style

The design system establishes an environment of strict auditability, factual verification, and autonomous consumer defense. It serves discerning buyers, enterprise procurement officers, and autonomous shopping agents operating under critical scrutiny. 

The aesthetic is Modern Technical Minimalism combined with Low-Contrast Precision Bordering:
- **Tone & Mood:** Impartial, evidentiary, forensic, and uncompromised. The visual weight mimics verified laboratory ledgers and algorithmic terminal interfaces rather than consumer e-commerce storefronts.
- **Visual Restraint:** Color is never decorative. It operates strictly as an indicator of epistemic status (verified facts, algorithmic inferences, independent flags, and safety overrides).
- **Audit Primacy:** UI hierarchy elevates the audit chain—every autonomous decision, rating, and comparative assertion exposes its underlying evidentiary trail and source provenance on demand.

## Colors

The system is calibrated around a disciplined dark slate spectrum to minimize ocular fatigue during exhaustive comparative reading while conferring clinical precision.

### Color Roles
- **Canvas Base (`#0b0f19`):** Deep abyssal slate background providing stable foundation.
- **Surface Layer 1 (`#0f172a`):** Primary panel, container, and layout card ground.
- **Surface Layer 2 (`#1e293b`):** Interactive inputs, nested inspect panels, table headers, and elevation tiers.
- **Surface Layer 3 (`#334155`):** Hover states, divider rules, and active selection borders.
- **Primary / Telemetry (`#38bdf8`):** Pure electric sky cyan. Reserved strictly for agent activity cycles, verified execution pathways, affirmative validation, and terminal focal points.
- **Secondary / Cited Warning (`#f59e0b`):** Deep amber. Strictly reserved for third-party conflict flags, ambiguous retailer specs, pending human intervention, and cautionary audit items.
- **Tertiary / Critical Flag (`#ef4444`):** Pure signal red. Exclusively deployed for detected deceptive patterns, fake review cascades, counterfeit alerts, and price gouging triggers.
- **Neutral / Structural (`#64748b` - `#94a3b8`):** Muted slate tones designating structural borders, metadata labels, and inactive control thresholds. Text layers rely on `#f8fafc` for maximum readability.

### Operational Separation
- **Live Autonomous Stream:** Framed by subtle pulsing primary cyan glow (`rgba(56, 189, 248, 0.25)`) and monospace status markers.
- **Demo / Static Evidence Snapshot:** Framed by static dashed zinc borders (`#475569`) with an indelible top-bar token denoting immutable read-only state.

## Typography

The typographic hierarchy enforces rapid visual triangulation between three categorical content types:

1. **Display & Structural Headings (Plus Jakarta Sans):** High legibility with tight kerning. Delivers clean, executive-level summaries and product names without editorial flourish.
2. **Body & Argumentative Deliberation (Inter):** Highly neutral, utilitarian letterforms for prolonged reading of trade-off rationale, synthetic review summarization, and vendor discrepancy reports.
3. **Forensic Telemetry & Auditing Logs (JetBrains Mono):** Dedicated to confidence matrices, timestamp hashes, HTTP payload references, cited source metadata, and autonomous agent thought-stream outputs.

Text color scales strictly with cognitive priority: primary headers use `#f8fafc` (high contrast), standard prose uses `#cbd5e1`, secondary descriptions use `#94a3b8`, and non-essential system timestamps use `#64748b`.

## Layout & Spacing

The system leverages a responsive 12-column split-workbench layout designed for high-density verification.

### Form Factors & Adaptability
- **Desktop (1280px+):** Tri-pane synchronized view:
  - *Left Pane (3 cols):* Autonomous Agent Reasoning & Query Workflow.
  - *Center Pane (5 cols):* Product Matrix & Direct Comparison Cards.
  - *Right Pane (4 cols):* Forensic Evidence Ledger, Source Citations, & Human Authorization Terminal.
- **Tablet (768px - 1279px):** Bi-pane layout. Agent reasoning and evidence consolidate into a tabbed collapsible drawer; product matrix occupies the primary canvas.
- **Mobile (<768px):** Single-column stacked stream. Product comparison collapses to vertical accordion cards with swipeable metric breakdowns. The human approval trigger is pinned to the bottom viewport edge as a persistent utility banner.

### Spacing Cadence
Spacing follows an exact 4px/8px incremental scale (`space-xs` through `space-xl`). Dense spatial budgeting is prioritized in telemetry cards (`space-sm` to `space-md`), whereas reading spaces and cross-product gaps rely on `space-lg` to prevent dense information bleed.

## Elevation & Depth

Visual hierarchy operates via tonal surfacing and crisp boundary definitions rather than blurred atmospheric shadows.

- **Stacking Surfaces:**
  - Base canvas: `#0b0f19`
  - Elevated containers & data rows: `#0f172a`
  - Overlays, popovers, and sticky inspection headers: `#1e293b`
- **Low-Contrast Structural Outlines:**
  Containers, tabular cells, and card elements rely on `1px solid rgba(148, 163, 184, 0.12)` to establish clear borders without visual noise. Active containers upgrade to `1px solid rgba(56, 189, 248, 0.4)`.
- **Intervention Elevation:**
  When a critical flag (amber/red) triggers human authorization, the target card creates depth via a high-contrast perimeter highlight (`1px solid #f59e0b` or `1px solid #ef4444`) accompanied by an inset, razor-sharp edge illumination (`0 0 0 1px rgba(245, 158, 11, 0.2)`).

## Shapes

The interface employs a disciplined Soft shape aesthetic (`roundedness: 1`), keeping elements crisp, purposeful, and aligned with industrial instrumentation.

- **Standard Containers & Cards:** `0.25rem` (4px) corner radii. Avoids playful or toy-like aesthetics, enforcing an analytical, tool-grade identity.
- **Interactive Badges, Metric Chips, & Pills:** Strict `0.25rem` (4px) to preserve monospace metric tabular alignment.
- **Action Buttons & Inputs:** `0.25rem` corner radii with inset crisp boundaries.
- **Modal Viewports & Snapshot Fixtures:** `0.5rem` (8px) corner radii at top level boundaries to signify macro boundaries.

## Components

### Buttons & Verification Controls
- **Primary Execution (Approve & Purchase):** Solid `#38bdf8` background, `#0b0f19` bold text, sharp 4px radius. In active states, features an animated sub-border shimmer.
- **Secondary (Inspect Evidence / Re-run Simulation):** Surface `#1e293b`, text `#f8fafc`, border `1px solid #334155`. Hover transitions to border `#64748b`.
- **Veto / Reject Order:** Surface `rgba(239, 68, 68, 0.1)`, text `#ef4444`, border `1px solid rgba(239, 68, 68, 0.3)`.

### Telemetry Chips & Evidence Badges
- **Status Badges:** Text in `label-mono`, enclosed in 4px containers with 1px border.
  - *Affirmed / Neutral:* `#0f172a` ground, `#94a3b8` text, border `#334155`.
  - *Flagged Claim (Amber):* `rgba(245, 158, 11, 0.1)` ground, `#f59e0b` text, border `rgba(245, 158, 11, 0.3)`.
  - *Counterfeit / Manipulation Alert (Red):* `rgba(239, 68, 68, 0.1)` ground, `#ef4444` text, border `rgba(239, 68, 68, 0.3)`.

### Product Comparison Matrix Cards
- Cards feature a structural two-tone build: a dark slate body (`#0f172a`) framed by an upper status band displaying autonomous confidence scores (0–100%) formatted in `JetBrains Mono`.
- Feature rows use alternating micro-borders (`1px solid rgba(148, 163, 184, 0.06)`). Any discrepancy between merchant assertions and verified user evidence triggers an inline amber or red citation tag with expandable provenance.

### Evidence Ledger & Citation Panel
- Chronological or metric-ranked list of cited sources (e.g., independent teardowns, consumer protection registries, price-history databases).
- Each citation exposes: domain identity, cryptographic audit timestamp, source trust weight (0.0 to 1.0), and verbatim excerpt highlight.

### Agent Reasoning Walkthrough (Scratchpad Stream)
- Monospace-accented sequential node stream connecting agent sub-tasks: `[FETCH_SPEC] -> [SCRAPE_REVIEWS] -> [FLAG_INCONSISTENCY] -> [SYNTHESIZE]`.
- Active nodes pulse via the primary sky-cyan accent; resolved nodes show static muted slate with expandable logic trees.

### Human Approval Flow (Intervention Gate)
- Pinned transactional container requiring intentional user consent whenever confidence drops below algorithmic threshold or cited warnings exceed zero.
- Displays explicit total financial exposure, return window guarantee rating, and a dual-button confirmation lock preventing accidental click-throughs.
